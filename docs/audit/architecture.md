# Architecture summary

Product: online placement, pre-test, post-test, and IELTS mockup for Titik Nol English Course, plus an internal staff dashboard. One Node.js monorepo, two apps sharing one PostgreSQL database on Neon. Plain `node:http`, no framework; `pg` is the only runtime dependency; three React 19 frontends bundled with esbuild, committed build outputs, and document shells generated by the Node servers.

Principals and protected resources. An anonymous test candidate holds only a server-minted attempt UUID and, for invited tests, an invite token hashed at rest plus a 6 character code. Admin users hold a `tnec_admin` session cookie, HttpOnly, SameSite=Strict, token hashed at rest. Protected resources: student identity (name, email, WhatsApp, birthplace, branch), exam answer keys, submitted attempts and recordings, certificates with public PDF link tokens, and the admin surface itself (question banks, levels, settings). External services are outbound-only peers: AttCos, Cloudflare Email and Browser Run, Speechace, Gemini. AttCos additionally makes one inbound fetch of a certificate PDF behind an unguessable token (`/cert-file/<token>`, no session).

Trust boundaries. 1) Anonymous web to public API: attempt UUID as bearer credential, per-action state gates, 16 to 64 KB body caps, server-side grading. 2) Invite token to attempt: hash lookup, used/expired/code-lock gates, atomic code tries. 3) Admin session gate plus Origin check on writes, both in `apps/admin/src/api.js`; no per-object role separation between `admin` and `pendidikan` (no route checks role). 4) Result link and cert-file token: bearer secrets stored plaintext in the database. 5) Upload boundaries: speaking audio 3 MB with mime whitelist and duration gates; certificate PDF 6 MB transport with `%PDF` magic check only. 6) Outbound integration boundary: no student contact data leaves except through the channels that exist to carry it; Speechace sees a sha256 of the attempt id, Gemini sees essay and prompt only. 7) Static serving: resolve-plus-prefix traversal guard applied on both layers. 8) Background workers are privileged by residency (result delivery, Speechace scoring, invite queue) and enforce their own leases and idempotence.

Strongest source-visible controls: SQL parameterized end to end with interpolation restricted to fixed fragments; all server-rendered HTML escaped; PBKDF2 600,000 iterations with timing-safe compare; per-account lockout; Origin check plus SameSite=Strict as the CSRF defense; body caps at transport and parse layers; 30 day audio purge; hashed session and invite tokens.

Comparable baseline: the data layer ports Cloudflare D1 semantics onto Postgres, and the handler shape follows the Workers fetch-handler convention; both are well-trodden patterns with no known inherited weakness.

Entry surfaces to sinks worth naming: public API routes (`apps/web/src/api.js`), admin route table (`apps/admin/src/api.js:266-333`), CSV roster import, three upload routes, certificate PDF render through Cloudflare Browser Run, the client context menu `innerHTML` sink (`apps/admin/client/src/menus.jsx:43`), and `dangerouslySetInnerHTML` for certificate numbers (escaped first).

Deployment facts outside source, decisive for several controls: `TRUST_PROXY=1` and TLS on Render (the Secure cookie flag and the Origin check both depend on the derived scheme), `ADMIN_SETUP_CODE` on Render, the Neon `sslmode` triggering `verify-full`, live response headers, and AttCos channel state. These stay needs_validation.

Execution policy for this run: source review plus the existing offline `npm test` knowledge only. The Windows host cannot enforce the required OS sandbox (no loopback-only network namespace, no kernel read-only root, no hard CPU or memory caps), so no target-controlled execution was run; every candidate that needs runtime proof carries that exact blocker.

Companion selection: WEB-PROTOCOL-AND-AUTH.md for the session, invite, token, and CSRF boundaries; CLIENT-SIDE.md for the React rendering sinks and browser storage; DATA-ISOLATION-AND-LIFECYCLE.md for student, lead, attempt, and audio lifecycle including the plaintext token trade-off; RESOURCE-EXHAUSTION-AND-AVAILABILITY.md for body caps, the unthrottled attempt creation, and the violation log growth. Memory safety, binary, desktop/mobile IPC, and supply-chain files are not selected: no native code, no extension, no mobile app, and the only runtime dependency is `pg`.

Starting paths: `apps/web/src/api.js`, `apps/admin/src/api.js`, `apps/admin/src/certificates.js`, `packages/core/src/{db,http,node-server,crypto,store,speaking,delivery,whatsapp,mailer,writing}.js`, `apps/admin/client/src/{menus.jsx,lib.js}`, `db/migrations/`.
